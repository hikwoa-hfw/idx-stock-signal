# Indonesian Stock Daily Signal Generator — BEI

Production-minded daily stock swing signal generator, tracking journal, and model evaluation system for Indonesian Stock Exchange (IDX/BEI) tickers.

Designed for local development with seamless cloud migration (AWS serverless / Lambda / EventBridge / RDS PostgreSQL) for remote access.

## AI Authorship Disclosure

Approximately 98% of this codebase was generated by AI coding agents under human direction, architectural constraints, and automated verification suites. The project owner designed the architecture, constraints, validation rules, and edge-case policies. AI agents implemented the code, tests, and documentation logs iteratively under those specifications.

## Quick Start (Local Setup)

### 1. Requirements
- Python 3.12+ (or 3.13)
- Node.js 24 LTS (for web/api apps)
- Git

### 2. Python Environment Setup
```bash
# Create and activate virtual environment
python -m venv .venv

# Windows Powershell:
.\.venv\Scripts\Activate.ps1

# Install baseline dependencies
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### 3. Environment Variables
```bash
cp .env.example .env
```
Adjust parameters in `.env` as needed.

### 4. Run Tests & Lint
```bash
# Full test suite (250 tests)
pytest

# Code linter
ruff check .
```

## CLI Pipelines & Usage

All pipeline commands are exposed via `Makefile` or direct Python modules:

| Pipeline | Command | Description |
|---|---|---|
| **Market Ingestion** | `make ingest` or `python -m scripts.ingest_daily --mode incremental` | Ingest BEI daily OHLCV & corporate actions via YFinance |
| **Feature Engine** | `make features` or `python -m scripts.build_features` | Compute causal momentum, trend, RSI, vol, & market regime features |
| **Label Engine** | `make labels` or `python -m scripts.build_labels` | Compute Triple Barrier labels (TP +5%, SL -2%, 10D expiry) |
| **Model Training** | `make train` or `python -m scripts.train_model` | Train walk-forward LightGBM / Logistic baseline models |
| **Backtesting** | `make backtest` or `python -m scripts.run_backtest` | Run event-driven simulation with IDX fees & slippage friction |
| **Daily Signals** | `make signals` or `python -m scripts.generate_signals --top-n 5` | Generate immutable daily Top-N candidate rankings & entry bands |
| **Telegram Dispatch** | `make telegram` or `python -m scripts.send_daily_telegram --dry-run` | Broadcast formatted daily signals report with medal ranks |
| **Position Journal** | `make positions` or `python -m scripts.manage_positions list` | Track actual portfolio trades (`/enter`, `/exit`, `/positions`) |
| **Outcome Engine** | `make outcomes` or `python -m scripts.resolve_outcomes --save-db` | Reconcile open signals against market bars & export matured outcomes |
| **Model Evaluation** | `make evaluate` or `python -m scripts.evaluate_models --from-outcomes` | Evaluate probabilistic calibration & Champion vs. Challenger gates |
